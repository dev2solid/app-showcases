# Fit Streak

A gym accountability app combining workout logging, progress history, and social motivation. The supplied development conversation initially calls the app Streak Buddy; final branding remains to be checked against the current source.

## Workflow

Start a workout → search and select exercises → log weight and reps → use rest timers between sets → finish the session → review workout details and progress in History.

## Engineering and interface

The development record describes React, TypeScript, Vite, Tailwind, and a Supabase integration with local fallback storage. It includes onboarding, workout templates, personal-record detection, friend codes, groups, leaderboards, and progress charts. The interface evolved toward black-and-gold styling with green completion feedback and mobile bottom navigation.

## Verification scope

These features are reported in the supplied development conversation. Current source, persistence behavior, social authorization, and calculations require independent checks before a runnable public release. No real fitness histories, profiles, or account configuration belong in the showcase.
