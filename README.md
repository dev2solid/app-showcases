# Product & Workflow Showcases

Six applications exploring practical problems: meal preparation, personal style, shared event memories, fitness accountability, friendly predictions, and grounded resume tailoring.

These are **product and engineering case studies**, not source-code releases or live demos. Each page separates observed implementation from development-history reports and future work. Personal media, account data, private deployment links, and credentials are excluded.

| Project | Problem it addresses | Engineering focus |
| --- | --- | --- |
| [PrepPilot](preppilot.md) | Turn a budget and pantry into a weekly meal plan | PWA shell, onboarding, browser persistence |
| [Dress Code](dress-code.md) | Organize shopping screenshots and review clothing previews | Codex inbox workflow, provenance, human review |
| [NightShare](nightshare.md) | Collect event photos across different phones | Optimistic uploads, realtime updates, original-media viewer |
| [Fit Streak](fit-streak.md) | Make workouts easier to log and revisit | Session state, rest timers, progress and accountability |
| [Sidepot / Betly](sidepot.md) | Track friendly predictions and their outcomes | Settlement state, leaderboard, per-friend history |
| [One of One — Resume Studio](resume-studio.md) | Tailor resumes without inventing experience | Source-grounded workflow, reviewable document outputs |

## What to explore

Dress Code and Resume Studio show how a user-initiated Codex workflow can support a focused application. The other projects demonstrate product implementation and workflow design; they are not presented as AI systems merely because AI tools helped build them.

For runnable technical projects, see [Counterexample Lab](https://github.com/dev2solid/counterexample-lab), [Agent Time Machine](https://github.com/dev2solid/agent-time-machine), [Evidence Room](https://github.com/dev2solid/evidence-room), and [Workflow Foundry](https://github.com/dev2solid/workflow-foundry).
